# 專案策略與知識庫（全域）

> 專案規範、工作流程、架構知識與工具安全協議。隨任務類型按需參照。

## 1. 子代理工作模式

你被 Claude Code 主代理調度時，會收到一份自包含的任務描述。遵循以下工作模式：

### 1.1 任務執行流程

1. **理解任務** — 讀取任務描述，確認目標、範圍、預期輸出格式
2. **搜尋與分析** — 使用 `search_file_content`、`glob`、`read_file` 等工具蒐集證據
3. **結構化輸出** — 按 GEMINI.md 定義的輸出格式標準產出結果
4. **標註限制** — 明確列出搜尋範圍、已知盲點、信心等級

### 1.2 任務類型對照

| 任務類型 | 重點 | 輸出要求 |
|---------|------|---------|
| 程式碼搜尋 | 完整覆蓋、多命名變體 | 檔案:行號 列表 + 呼叫關係 |
| 日誌分析 | 時序追蹤、模式識別 | 時間軸 + 錯誤分類 + 根因推測 |
| 影響分析 | 跨層追蹤、間接依賴 | 依賴圖 + 受影響檔案清單 |
| 批判性審查 | 挑戰假設、找盲點 | 假設挑戰表 + 替代方案 |
| 審查輔助 | 交叉驗證、擴大掃描 | 驗證結果 + 新發現 |
| 文件萃取 | 重點提取、結構化 | 摘要 + 關鍵數據表 |

### 1.3 信心標註

每個重要結論必須標註信心等級：

- **確認** — 有直接程式碼/日誌證據
- **高度可能** — 多項間接證據支持
- **推測** — 基於模式推斷，需驗證

## 2. 程式碼分析知識

### 2.1 SOLID 速查（審查輔助用）

| 原則 | 紅旗標誌 |
|------|---------|
| **SRP** | class 名含 `And`/`Manager` 但職責不明確；method 超過 3 個主要動作；依賴超過 7 個 class |
| **OCP** | `switch/case` 或 `if-else` 鏈處理類型判斷；修改現有 class 支援新功能 |
| **LSP** | 子類別覆寫拋出 `NotImplementedException`；改變父類別方法預期行為 |
| **ISP** | 介面方法超過 5 個；實作有空方法或 `NotSupported` |
| **DIP** | 直接實例化具體類別（非 DTO/Entity）；高層 import 低層具體類別 |

### 2.2 多層架構速查

| 層級 | 允許 | 禁止 |
|------|------|------|
| **Controller** | Request → Service → Response | 業務邏輯、Repository 直呼 |
| **Validation** | 格式與型別驗證 | DB 查詢、業務判斷 |
| **Service** | 業務規則、狀態檢核、交易 | — |
| **Repository** | CRUD 資料存取 | 業務邏輯 |

## 3. 工具安全協議（若需要編輯檔案）

> 研究任務通常不需要修改檔案。若任務明確要求修改，遵循以下規範。

### 3.1 原子化替換

- 每次 `replace` 只修改一個方法
- 「修改 A」+「新增 B」必須拆為兩步
- `old_string` 只包含定位點，不包含整個函式

### 3.2 消失檢查

執行 `replace` 前，比對 `old_string` 與 `new_string` 中的 `function` 關鍵字數量。若 `new` 少於 `old` 且非刻意刪除，立即停止。

### 3.3 唯一匹配

多個方法結構相似時，`old_string` 必須包含該方法獨有的標誌（特定方法呼叫、Apidoc 標題等），或拆分為更精確的區塊分別替換。

---

## 4. 呼叫鏈追蹤方法論

分析跨層功能時，按以下步驟追蹤：

1. **入口點定位** — `glob` 找 Controller/Command，`search_file_content` 找路由定義
2. **Service 層展開** — 讀取入口點，找到呼叫的 Service 方法
3. **Repository/Model 層** — 追蹤 Service 內的資料存取呼叫
4. **間接依賴** — 檢查 Event、Observer、Middleware、Job 等非同步/隱式呼叫
5. **動態初始化警覺** — `app('Service')->init(...)` 等動態呼叫，靜態 grep 可能遺漏

### 追蹤記錄格式

```
Controller::method (檔案:行號)
  → Service::method (檔案:行號)
    → Repository::method (檔案:行號)
      → DB Query: {table}.{column} (檔案:行號)
    → Event::dispatched (檔案:行號) [非同步]
      → Listener::handle (檔案:行號)
```
