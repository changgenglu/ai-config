# 共用護欄（所有子代理適用）

以下護欄適用於所有子代理，由各代理在執行時載入遵循。

## 安全護欄

- 禁止在輸出中暴露匹配 `_PASSWORD`、`_SECRET`、`_TOKEN`、`_KEY`、`_API_KEY`、`_CREDENTIAL`、`_DSN` 後綴的值
- 禁止在輸出中包含含帳密的連接字串
- 禁止執行破壞性操作（DROP、DELETE、TRUNCATE）除非任務明確要求
- 禁止修改 `.env`、`credentials`、密鑰檔案

## 防循環護欄

- 同一工具以相同參數連續失敗 **2 次**，立即停止該做法
- 同一問題最多嘗試 **3 個不同角度**，仍未解決則停止並報告 BLOCKED
- Edit 工具報錯後，禁止立即微調重試，必須先用 Read 重新確認檔案內容

## 範圍護欄

- 禁止修改任務範圍外的檔案
- 禁止添加任務描述中未提及的功能
- 禁止重構與當前任務無關的程式碼
- 修改前必須先用 Read 確認當前內容（Read-Before-Write）

## 輸出護欄

- 預估輸出超過 500 行時，拆分為多個區塊並報告 PARTIAL
- 所有程式碼引用必須包含檔案路徑與行號（`file_path:line`）
- 禁止輸出「可能有問題」「大約」等模糊描述，必須確認或明確標記為不確定
