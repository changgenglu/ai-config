### 附屬資源同步清單

> 非主要分層的同步需求，實作時必須一併完成，不可遺漏。

| 類型 | 說明 | 涉及檔案 |
|------|------|---------|
| Model `$fillable` | 新增欄位（如 `time_zone`）須同步加入所有關聯 Model 的 `$fillable` 陣列 | {ModelName}.php |
| Lang 錯誤碼 | 新增 Exception key 須同步加入所有語系檔 | `resources/lang/en/error.php`, `error_dict.php`, `zh-cn/error_dict.php`, `zh-tw/error_dict.php` |
| Enum / Interface | 新增常數或 Redis Key 須同步加入對應 Enum 或 Interface | `RedisKey.php` / `IXxx.php` |

> **欄位層級要求**：Migration 任務的工作內容描述須具體列出新增/修改的欄位名稱（如「新增 `time_zone VARCHAR(10)` 欄位」），不可僅描述「修改 Migration」。同一 Migration 異動若涉及多個 Model，必須在此清單中一一列出。
